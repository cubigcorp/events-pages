CUBIG 배호 공동대표가 2026년 12월 15일 전자신문인터넷이 여는 온라인 웨비나 Agent-Ready Data 웨비나 2027에서 첫 세션(14:00~14:40)을 발표합니다. 세션 제목은 'Agent 성능을 설계하는 데이터 전략: PoC를 넘어 Production으로'입니다.

CUBIG이 보여줄 것

주요 내용

  1. 01
    테스트에서 놓친 예외가 현장에서 나타나는 AI Agent 도입의 고민
  2. 02
    업무 데이터에 빠진 상황을 Syntitan으로 검증 케이스로 만드는 방법
  3. 03
    검증 결과를 데이터 보완으로 잇는 접근
  4. 04
    업무 기준이 바뀌었을 때 기존 검증 자산으로 다시 점검하는 방향
  5. 05
    Agent를 테스트에서 실제 운영으로 옮기는 AI-Ready Data의 역할
