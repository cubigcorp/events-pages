CUBIG joins the Agent Korea and Public AX Talk Concert as an official sponsor. Public AX Network and Agent Korea host the event together. It is their second joint event.

The event runs on November 22, 2026, at the AWS auditorium, Centerfield East 18F, in Seoul. It is for public-sector staff leading AI adoption and for company staff using AI coding agents.

CUBIG gives a 10-minute talk before networking. It covers how two public institutions prepared their own data for AI work.

What CUBIG brought

  1. 01Two public-sector cases of preparing institutional data for AI work
  2. 02Constraints to check first: personal data in the data and limits on moving it outside
  3. 03How sensitive values are replaced with context-preserving substitutes before reaching AI, and original values are restored in the response (LLM Capsule)
  4. 04How Syntitan checks whether data fits an AI task
