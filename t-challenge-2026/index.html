CUBIG finished 2nd of 12 finalists at T Challenge 2026, the global open innovation program run by Deutsche Telekom and T-Mobile US. It was a first for a Korean company.

The theme was Building the AI-native Telco. Finalists spent three months building and validating their solutions for real telecom environments.

What CUBIG brought

→Context-Preserving Data Layer for AI
  1. 01
    LLM Capsule as the layer that lets LLMs and agents work with telecom operational data
  2. 02
    Network configurations, logs and incident records restructured into a form AI can use
  3. 03
    Sensitive values replaced with context-preserving substitutes by policy, keeping document format, table structure and log flow
  4. 04
    Results restored to the original business values inside the workflow
  5. 05
    Works as a plug-in to existing tools or as a standalone web app
